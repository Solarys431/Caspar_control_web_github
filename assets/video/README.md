# Video Folder

Video MP4, MOV, AVI, MKV serviti via HTTP per CasparCG.

## Formati supportati
- MP4, MOV, AVI, MKV, WMV, FLV, WEBM

## Utilizzo
- Accessibili via: `http://100.64.211.9:5000/assets/video/nome_video.mp4`

## Comandi CasparCG
```amcp
PLAY 1-1 "http://100.64.211.9:5000/assets/video/intro.mp4"
PLAY 1-2 "http://100.64.211.9:5000/assets/video/commercial.mov" LOOP
```
