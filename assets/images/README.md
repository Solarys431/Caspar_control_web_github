# Images Folder

Cartella per immagini PNG, JPG, SVG, GIF servite via HTTP per CasparCG.

## Formati supportati
- PNG, JPG, JPEG, SVG, GIF, BMP, TGA

## Utilizzo
- Accessibili via: `http://100.64.211.9:5000/images/nome_immagine.png`

## Comandi CasparCG
```amcp
PLAY 1-1 "http://100.64.211.9:5000/images/background.jpg"
PLAY 1-2 "http://100.64.211.9:5000/images/logo.svg"
```
